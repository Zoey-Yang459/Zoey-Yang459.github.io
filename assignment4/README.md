## Run locally

Place the Python file and dataset in the same directory. From that directory, run:

```bash
python3 -m pip install -r requirements.txt
python3 Part_1.py
```

The two PNGs will be written to `plots/`. The script calls `plt.show()` on an interactive desktop; in headless environments use `MPLBACKEND=Agg python3 Part_1.py` (this may emit non-interactive canvas warnings, but still saves the figures).

The Python implementation uses no machine-learning toolkits. The original code, from-scratch Naive Bayes, uses only Python's standard library and Matplotlib.
