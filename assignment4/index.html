02 · METHODOLOGY

Naive Bayes from first principles

The classifier models a document as a sequence of word occurrences. Under the conditional-independence assumption, its class-specific joint probability is the class prior multiplied by the likelihoods of all tokens. To avoid numeric underflow, we sum log probabilities instead:

The normalizing quantity P(document) is the same for both classes and is unnecessary when comparing scores.

Estimating the model

train_nb(documents, labels, alpha=1.0) counts labeled training documents, collects token frequencies separately for each sentiment, and builds the training vocabulary. The estimated priors are P(pos) = 0.508551 and P(neg) = 0.491449.

The main model uses additive (Laplace) smoothing with α = 1. An additional unknown-token slot is reserved, enabling score_doc_label() to score words unseen during training:

Nw,c is the frequency of word w within class c; Nc is the total token count for that class; |V| = 52,392.

Finally, classify_nb() selects the label with the larger score, and classify_documents() repeats this for every evaluation review.

04 · ERROR ANALYSIS

Why are some reviews misclassified?

The Multinomial Naive Bayes classifier correctly classified 1,943 of the 2,383 evaluation reviews, achieving an accuracy of 81.54%. Among the 440 misclassified reviews, 193 negative reviews were predicted as positive, while 247 positive reviews were predicted as negative.

Examining individual misclassifications revealed several limitations of the bag-of-words approach.

Mixed sentiment and negation: Review 545 was classified as positive despite its negative label. The reviewer described the product as “great at exfoliating” but ineffective at hair removal. The model gave excessive weight to positive expressions without adequately accounting for negation.

Context-dependent sentiment: Review 1813 was incorrectly classified as negative, although it recommended the purchased battery. The review contained strongly negative language about competing batteries. Since Naive Bayes does not explicitly model relationships between words and their subjects, it could not reliably distinguish criticism of competitors from criticism of the reviewed product.

Ambiguous overall evaluations: Review 1092 described a camera bag as small but also mentioned that it fit the camera well and remained useful for informal situations. Review 2069 expressed enjoyment of a film while questioning its DVD presentation format. These examples demonstrate how mixed evaluations can make the overall sentiment difficult to determine from individual word frequencies.

Potential labeling inconsistencies: Review 1558 was labeled negative, although its content was strongly positive, describing the television series enthusiastically and encouraging others to watch it. This suggests a possible inconsistency in the dataset labels rather than necessarily a failure of the classifier.

Overall, the analysis highlights the limitations of Multinomial Naive Bayes in handling negation, mixed sentiment, contextual relationships, and possible label noise. Despite these challenges, the classifier achieved reasonable performance using a relatively simple probabilistic model.

Selected examples

Five misclassified examples were inspected directly from the evaluation set. Their zero-based indices below refer to eval_docs. They show how a word-frequency model can overlook context, negation and mixed opinions. The five are short-to-medium reviews (53–88 tokens, against a median of 103 over the evaluation set) that the model gets wrong with high confidence: the log-score margin toward the wrong class is 6.7–10.6, which corresponds to a Naive Bayes posterior above 99.8% for the wrong label. They were chosen as representative cases, not as the single most confident errors.

Interpretation. Multinomial Naive Bayes is efficient and effective, but independent word counts do not capture word order, negation scope, sentiment targets, or potentially noisy ground-truth labels. It is also overconfident: the independence assumption multiplies evidence from correlated words, so wrong predictions can carry very large margins (a log-score gap of about 127 for one 2,644-token review).

07 · CONCLUSION

Findings and limitations

A Multinomial Naive Bayes classifier implemented without a machine-learning toolkit achieved 81.54% evaluation accuracy with additive smoothing and log probabilities. The learning curve shows the value of additional labeled training data, while informative-word rankings reveal recognizable sentiment signals as well as domain effects. Error analysis highlights persistent challenges with negation, mixed judgments, the target of sentiment, and possible label noise.

Possible future extensions include explicit negation handling, unigram-plus-bigram features, and cross-domain tests. These are not part of the implementation evaluated here.

Reproducibility. The complete, unchanged student Python file, original review dataset, and both generated figures accompany this report. The Python implementation uses only the standard library and Matplotlib; no scikit-learn Naive Bayes classifier is used.

def train_nb(documents, labels, alpha=1.0):

    # Count the number of documents in each class
    class_counts = Counter(labels)

    # Count word occurrences separately for each class
    word_counts = {
        label: Counter() for label in class_counts
    }

    for doc, label in zip(documents, labels):
        word_counts[label].update(doc)

    # Vocabulary contains all distinct training words
    vocabulary = set()

    for counts in word_counts.values():
        vocabulary.update(counts.keys())

    # Total number of word occurrences in each class
    total_words = {
        label: sum(word_counts[label].values())
        for label in class_counts
    }

    # Class priors: P(class)
    priors = {
        label: class_counts[label] / len(documents)
        for label in class_counts
    }

    # Store everything required for classification
    model = {
        "priors": priors,
        "word_counts": word_counts,
        "total_words": total_words,
        "vocabulary": vocabulary,
        "alpha": alpha
    }

    return model

import math

def score_doc_label(document, label, model):

    # Get parameters learned during training
    prior = model["priors"][label]
    counts = model["word_counts"][label]
    total = model["total_words"][label]
    alpha = model["alpha"]

    # Reserve one vocabulary entry for unknown words
    vocab_size = len(model["vocabulary"]) + 1

    denominator = total + alpha * vocab_size

    # Start with the log prior
    log_score = math.log(prior)

    # Add each word's log likelihood
    for word in document:

        word_count = counts[word]

        word_probability = (
            (word_count + alpha) / denominator
        )

        log_score += math.log(word_probability)

    return log_score

def classify_nb(document, model):

    # Find the class with the highest log score
    best_label = max(
        model["priors"],
        key=lambda label: score_doc_label(
            document, label, model
        )
    )

    return best_label

def accuracy(true_labels, guessed_labels):

    correct = 0

    for true, predicted in zip(true_labels, guessed_labels):
        if true == predicted:
            correct += 1

    return correct / len(true_labels)

print("\nOptional Task: Informative Words")

# Use higher smoothing for stable word rankings
feature_alpha = 50.0

feature_model = train_nb(
    train_docs,
    train_labels,
    alpha=feature_alpha
)

pos_counts = feature_model["word_counts"]["pos"]
neg_counts = feature_model["word_counts"]["neg"]

vocab_size = len(feature_model["vocabulary"]) + 1

pos_denominator = (
    feature_model["total_words"]["pos"]
    + feature_alpha * vocab_size
)

neg_denominator = (
    feature_model["total_words"]["neg"]
    + feature_alpha * vocab_size
)

word_scores = []

for word in feature_model["vocabulary"]:

    # Exclude punctuation, short and rare tokens
    if not word.isalpha() or len(word) < 3:
        continue

    total_count = pos_counts[word] + neg_counts[word]

    if total_count < 40:
        continue

    pos_prob = (
        (pos_counts[word] + feature_alpha)
        / pos_denominator
    )

    neg_prob = (
        (neg_counts[word] + feature_alpha)
        / neg_denominator
    )

    log_ratio = math.log(pos_prob) - math.log(neg_prob)

    word_scores.append((word, log_ratio))

# Rank words using the log-likelihood ratio
top_positive = sorted(
    word_scores,
    key=lambda item: (-item[1], item[0])
)[:10]

top_negative = sorted(
    word_scores,
    key=lambda item: (item[1], item[0])
)[:10]

print("\nTop 10 Positive Words:")
for word, score in top_positive:
    print(f"{word:18s} {score:+.4f}")

print("\nTop 10 Negative Words:")
for word, score in top_negative:
    print(f"{word:18s} {score:+.4f}")
