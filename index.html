PART ONE

Shortest Distance from a Point to a Function

The objective is to determine the shortest Euclidean distance from a given point \((x_0,y_0)\) to a continuous function \(y=f(x)\). I solve the problem analytically and numerically using Newton–Raphson and Golden Section Search.

Objective Function

For a point \((x,f(x))\) on the curve, the squared Euclidean distance is

\[ D(x)=(x-x_0)^2+(f(x)-y_0)^2. \]

Minimizing \(D(x)\) is equivalent to minimizing the actual distance \(d(x)=\sqrt{D(x)}\), because the square root is monotonically increasing.

Required Function

\[ f(x)=x^2+5 \] \[ (x_0,y_0)\in \{(0,0),(-4,0),(-8,0),(2,0),(6,0)\}. \]

Analytical Solution

Because all required points have \(y_0=0\),

\[ D(x)=(x-x_0)^2+(x^2+5)^2. \] \[ D'(x)=2(x-x_0)+4x(x^2+5). \] \[ D'(x)=4x^3+22x-2x_0. \] Setting \(D'(x)=0\), \[ \boxed{2x^3+11x-x_0=0}. \] Also, \[ D''(x)=12x^2+22>0, \] so the critical point is the unique global minimum.

Part 1 — Newton–Raphson Method

Newton–Raphson finds a root of \(D'(x)=0\) using

\[ x_{k+1}=x_k-\frac{D'(x_k)}{D''(x_k)}. \] For \(f(x)=x^2+5\), \[ \boxed{ x_{k+1} = x_k- \frac{2x_k^3+11x_k-x_0} {6x_k^2+11} }. \]

The required data points converge to the same minima as the analytical solution. The figures below show the early iteration steps and final shortest-distance location.

Part 1 — Golden Section Search

Golden Section Search minimizes the squared-distance objective without requiring derivatives. At every step the search interval is reduced using the golden ratio, retaining the subinterval containing the smaller objective value.

\[ D(x)=(x-x_0)^2+(f(x)-y_0)^2 \] \[ \phi=\frac{1+\sqrt5}{2}. \]
Result: Newton–Raphson and Golden Section Search agree with the analytical minima for all five required points.

PART TWO

Fitting Functions by Minimizing Mean Squared Error

The data points are \[ (0,0.5),\quad(2,3.5),\quad(1,1.5),\quad(3,7.5). \] A line and a parabola are fitted by minimizing mean squared error (MSE). I solve each problem analytically and then reproduce the result numerically using sequential Newton–Raphson parameter updates.

For \(n=4\) data points, \[ MSE=\frac{1}{4}\sum_{i=1}^{4}(\hat y_i-y_i)^2. \]

Part 2 — Line Fit

Analytical Formulation

Let

\[ \hat y=mx+b. \]

The MSE for the four data points is

\[ MSE(m,b) = \frac14 \left[ (b-0.5)^2 +(2m+b-3.5)^2 +(m+b-1.5)^2 +(3m+b-7.5)^2 \right]. \] Expanding, \[ \boxed{ MSE(m,b) = 3.5m^2+b^2+3mb-15.5m-6.5b+17.75 }. \]

Analytical Minimization

\[ \frac{\partial MSE}{\partial m} = 7m+3b-15.5=0, \] \[ \frac{\partial MSE}{\partial b} = 3m+2b-6.5=0. \] Therefore, \[ \boxed{m=2.3,\qquad b=-0.2}. \]
\[ \boxed{\hat y=2.3x-0.2} \] \[ \boxed{MSE_{\text{line}}=0.575}. \]

Sequential Newton–Raphson Updates

Starting from \(m_0=0\) and \(b_0=0\), the slope is updated first while holding the intercept fixed. The intercept is then updated using the new slope.

\[ m_{k+1} = m_k- \frac{7m_k+3b_k-15.5}{7} = \boxed{\frac{15.5-3b_k}{7}}, \] \[ b_{k+1} = b_k- \frac{2b_k+3m_{k+1}-6.5}{2} = \boxed{\frac{6.5-3m_{k+1}}{2}}. \]

Part 2 — Parabola Fit

Analytical Formulation

Use the general quadratic

\[ \hat y=ax^2+bx+c. \]

The MSE is

\[ MSE(a,b,c) = \frac14 \left[ (c-0.5)^2 +(4a+2b+c-3.5)^2 +(a+b+c-1.5)^2 +(9a+3b+c-7.5)^2 \right]. \] Expanding, \[ \boxed{ \begin{aligned} MSE(a,b,c) ={}& 24.5a^2+3.5b^2+c^2+18ab+7ac+3bc\\ &-41.5a-15.5b-6.5c+17.75. \end{aligned}} \]

Analytical Minimization

\[ \frac{\partial MSE}{\partial a} = 49a+18b+7c-41.5=0, \] \[ \frac{\partial MSE}{\partial b} = 18a+7b+3c-15.5=0, \] \[ \frac{\partial MSE}{\partial c} = 7a+3b+2c-6.5=0. \] Solving, \[ \boxed{ a=0.75,\qquad b=0.05,\qquad c=0.55 }. \]
\[ \boxed{\hat y=0.75x^2+0.05x+0.55} \] \[ \boxed{MSE_{\text{parabola}}=0.0125}. \]

Sequential Newton–Raphson Updates

Starting from \(a_0=b_0=c_0=0\), each coefficient is updated in sequence. The newest coefficient values are used immediately in the next parameter update.

\[ \boxed{ a_{k+1} = \frac{41.5-18b_k-7c_k}{49} } \] \[ \boxed{ b_{k+1} = \frac{15.5-18a_{k+1}-3c_k}{7} } \] \[ \boxed{ c_{k+1} = \frac{6.5-7a_{k+1}-3b_{k+1}}{2} }. \]
