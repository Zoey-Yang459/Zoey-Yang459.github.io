1. Problem Definition

The objective is to determine the shortest Euclidean distance between a given point and a continuous function. The primary function investigated in this assignment is the parabola \(y=x^2+5\).

Required Function

\[ y=f(x)=x^2+5 \]

Required Points

\[ (0,0),\quad (-4,0),\quad (-8,0),\quad (2,0),\quad (6,0) \]

Distance Function

Consider a given point \(P=(x_0,y_0)\) and a point on the function \(Q=(x,f(x))\). Their Euclidean distance is

\[ d(x)= \sqrt{ (x-x_0)^2+ (f(x)-y_0)^2 }. \]

Since the square-root function is monotonically increasing, minimizing the distance is equivalent to minimizing the squared distance:

\[ D(x)= (x-x_0)^2+ (f(x)-y_0)^2. \]

Working with \(D(x)\) simplifies both the analytical and numerical optimization procedures.

2. Analytical Approach

The analytical approach finds the stationary point of the squared-distance function using calculus.

Calculus

Squared Distance for \(y=x^2+5\)

Since all five required points have \(y_0=0\),

\[ D(x)= (x-x_0)^2+ (x^2+5)^2. \]

First Derivative

\[ D'(x) = 2(x-x_0) + 4x(x^2+5) \]
\[ D'(x) = 4x^3+22x-2x_0. \]

Setting \(D'(x)=0\) gives

\[ 2x^3+11x-x_0=0. \]

Second Derivative

\[ D''(x)=12x^2+22. \]

Since \(D''(x)>0\) for all real values of \(x\), the squared-distance function is strictly convex. Therefore, each stationary point corresponds to the unique global minimum.

3. Newton-Raphson Method

Newton-Raphson locates the stationary point of \(D(x)\) by solving \(D'(x)=0\) iteratively.

Numerical Method 1

General Update Equation

\[ x_{n+1} = x_n - \frac{D'(x_n)} {D''(x_n)}. \]

For the parabola \(y=x^2+5\),

\[ x_{n+1} = x_n - \frac{ 2x_n^3+11x_n-x_0 }{ 6x_n^2+11 }. \]

The \(x\)-coordinate of each input point was used as the initial guess. Iterations continued until

\[ |x_{n+1}-x_n|<10^{-7}. \]

Example: Point \((-8,0)\)

Starting with \(x^{(0)}=-8\), the first three Newton-Raphson iterations are

\[ -8 \rightarrow -5.205063 \rightarrow -3.296205 \rightarrow -1.985209. \]

Continuing the iterations produces

\[ x^*\approx -0.672078 \]

and therefore

\[ d_{\min} \approx 9.133420. \]

4. Golden Section Search

Golden Section Search minimizes the squared-distance function directly without requiring derivatives.

Numerical Method 2

Golden Ratio

\[ \phi = \frac{1+\sqrt5}{2}, \qquad r=2-\phi \approx0.381966. \]

For an interval \([a,b]\), two interior points are defined:

\[ x_1=a+r(b-a) \]
\[ x_2=b-r(b-a). \]

The values \(D(x_1)\) and \(D(x_2)\) are compared. The interval containing the smaller objective value is retained, and the process repeats until the interval becomes sufficiently small.

Example: Point \((-8,0)\)

The initial interval used was

\[ [-8,0]. \]

After the first three interval reductions:

\[ [-8,0] \rightarrow [-4.944272,0] \rightarrow [-3.055728,0] \rightarrow [-1.888544,0]. \]

Continuing the search converges to

\[ x^* \approx -0.672078 \]

with shortest distance

\[ d_{\min} \approx 9.133420. \]

8. Python Implementation

The numerical methods were implemented as reusable Python functions so that different points and functions can be passed directly into the same routines.

Newton-Raphson Core

def find_newton_distance(
    x0,
    y0,
    f,
    df,
    ddf,
    initial_guess=0.0,
    tolerance=1e-7,
    max_iter=100
):
    x = initial_guess
    history = [x]

    for _ in range(max_iter):

        D_prime = (
            2 * (x - x0)
            + 2 * (f(x) - y0) * df(x)
        )

        D_double_prime = (
            2
            + 2 * (df(x)**2)
            + 2 * (f(x) - y0) * ddf(x)
        )

        next_x = x - D_prime / D_double_prime

        history.append(next_x)

        if abs(next_x - x) < tolerance:
            x = next_x
            break

        x = next_x

    shortest_distance = (
        (x - x0)**2
        + (f(x) - y0)**2
    )**0.5

    return shortest_distance, x, history

Golden Section Search Core

def golden_section_search(
    x0,
    y0,
    f,
    a,
    b,
    tolerance=1e-7
):
    phi = (1 + math.sqrt(5)) / 2
    resphi = 2 - phi

    x1 = a + resphi * (b - a)
    x2 = b - resphi * (b - a)

    def dist_sq(x):
        return (
            (x - x0)**2
            + (f(x) - y0)**2
        )

    f_x1 = dist_sq(x1)
    f_x2 = dist_sq(x2)

    history = []

    while abs(b - a) > tolerance:

        history.append(
            (a, b, x1, x2, f_x1, f_x2)
        )

        if f_x1 < f_x2:

            b = x2
            x2 = x1
            f_x2 = f_x1

            x1 = a + resphi * (b - a)
            f_x1 = dist_sq(x1)

        else:

            a = x1
            x1 = x2
            f_x1 = f_x2

            x2 = b - resphi * (b - a)
            f_x2 = dist_sq(x2)

    best_x = (a + b) / 2

    return (
        math.sqrt(dist_sq(best_x)),
        best_x,
        history
    )

9. Discussion and Conclusion

The analytical, Newton-Raphson, and Golden Section Search approaches produced consistent minimum-distance results for all five required points.

Newton-Raphson converged rapidly because derivative information was available. However, it requires both the first and second derivatives of the function and an appropriate initial guess.

Golden Section Search required more iterations, but it did not require derivative information. Instead, it relied only on evaluations of the squared-distance objective over a valid search interval.

Testing a second parabola and the exponential function \(y=e^x\) demonstrated that the implementation can be reused for different polynomial and non-polynomial functions with only minor changes to the function definitions and search parameters.
